# ADR-0006: локальные X/Y и world transform

Статус: принято.

Дата: 2026-08-31.

## Контекст

Пользователь воспринимает X/Y как положение объекта. Текущие сцены используют top-left translate, а Scene уже хранит anchor, rotation и scale. Смена смысла X/Y сломает существующие темы.

## Решение

- X/Y — координата левого верхнего угла объекта в локальной системе родителя до rotation/scale.
- Anchor — нормализованная точка вращения/масштабирования внутри bounds.
- World transform вычисляется матрицами по одному алгоритму.
- Reparent сохраняет world-положение посредством пересчёта local transform.
- Scale/rotation группы воздействуют на всё поддерево.

## Последствия

- Сохраняется визуальная совместимость текущих сцен.
- Для точного hit testing каждый component kind обязан предоставлять bounds.
- Inspector может показывать простые X/Y, не объясняя пользователю матричную модель.

## Отклонённые варианты

- X/Y как позиция anchor в стиле After Effects — потребует миграции всех координат.
- Переписывать координаты детей при движении группы — разрушает локальную модель и history.
- Использовать разные CSS и Canvas формулы — создаёт Preview drift.

## Проверка

- Golden transform fixtures включают nested translate/scale/rotation/anchor.
- После reparent world corners совпадают с точностью до установленного epsilon.
- Preview handles совпадают с rendered bounds.
