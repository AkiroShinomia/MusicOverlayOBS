# ADR-0003: тема является полным снимком Scene

Статус: принято.

Дата: 2026-08-31.

## Контекст

В реальных данных большинство тем — полные Scene, одна тема использует `ref + overrides`. Пользовательская концепция — выбрать готовую композицию, настроить и сохранить свою копию. Live inheritance пользователю не требуется и создаёт непредсказуемые изменения после обновления встроенной темы.

## Решение

- В 2.1 builtin и custom theme хранят полный `music-overlay.scene` snapshot.
- `sourceThemeId` — только происхождение, не ссылка наследования.
- Builtin read-only.
- `Save as copy` создаёт независимую custom theme.
- Существующая ref-theme один раз разрешается в полный snapshot миграцией.

## Последствия

- Темы проще переносить, проверять и восстанавливать.
- Обновление встроенной темы не меняет пользовательские копии.
- Некоторые данные дублируются между файлами; общий Registry и Asset Catalog уменьшают существенное дублирование.

## Отклонённые варианты

- Ref + overrides — сложная цепочка разрешения, миграций и конфликтов.
- Изменяемая builtin theme — обновление приложения может уничтожить пользовательские изменения.

## Проверка

- Каждая тема проходит Scene validation без внешней scene reference.
- Пользовательская копия остаётся неизменной после замены builtin fixture.
- Builtin delete/update запрещены backend и UI.
