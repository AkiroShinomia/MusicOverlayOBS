# ADR-0005: модульность без обязательного bundler и native ESM

Статус: принято для Stage 2E; пересмотр после compatibility matrix.

Дата: 2026-08-31.

## Контекст

Overlay исполняется во встроенном браузере OBS. То, что он является веб-страницей, не гарантирует поддержку каждой современной возможности JavaScript/CSS во всех используемых версиях OBS. В проекте нет bundler, а его добавление усложнит portable build.

## Решение

- Stage 2E делит код на отдельные classic scripts.
- Экспорт идёт через один namespace `MusicOverlay`, внутри которого модули имеют узкие API.
- Порядок scripts явный и проверяется smoke test.
- Новые модули пишутся так, чтобы их чистая логика тестировалась без DOM.
- Native ESM вводится только после фиксации минимальной версии OBS и compatibility test.
- Bundler вводится только отдельным ADR с измеримой пользой.

## Последствия

- Совместимость выше, build остаётся простым.
- Нет compile-time import graph; dependency lint/test должен компенсировать это.
- Один namespace является временным техническим компромиссом, а не разрешением для новых глобальных mutable variables.

## Отклонённые варианты

- Немедленно перейти на ESM — риск сломать старый embedded browser без продуктовой выгоды этапа.
- Оставить один файл — противоречит цели рефакторинга.
- Сразу добавить крупный frontend toolchain — увеличивает release и update surface.

## Проверка

- Overlay запускается в выбранной минимальной OBS и обычном тестовом браузере.
- Каждый файл регистрирует один модуль и не создаёт произвольные globals.
- Pure-модули запускаются unit tests отдельно от HTML.
