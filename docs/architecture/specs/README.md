## Обязательная структура ТЗ

Каждое ТЗ содержит:

- цель и продуктовый результат;
- scope и non-goals;
- prerequisites;
- целевую структуру и контракты;
- порядок миграции;
- требования к UX и совместимости;
- acceptance criteria;
- test cases;
- риски и rollback;
- зависимости и traceability;
- открытые вопросы.

ТЗ считается готовым к разработке, когда в нём нет технического решения, оставленного исполнителю без рамок, и нет продуктового вопроса, меняющего acceptance criteria.
